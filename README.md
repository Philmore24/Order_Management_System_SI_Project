# Order Management System Project
Overview

This project is an ASP.NET-based Order Management System developed as part of a Software Implementation project.

The application was designed to support order-related business processes through a web-based interface. The project provided hands-on experience building and organizing an ASP.NET application, creating reusable user interface components, and working with application logic.

## Technologies & Tools

C#
ASCX User Controls
HTML
CSS

Git / GitHub
Key Features
Web-based order management interface
Reusable ASP.NET User Controls (.ascx)
Structured navigation and application pages
C# application logic
User interface components for managing order-related functions
Separation of reusable controls from individual application pages
